# SmartBudgetManager
A project for managing Budget.
Product Overview
SmartBudget Manager is an automated Microsoft Excel workbook designed to streamline personal and small 
business monthly financial tracking, expense categorization, and budget limit monitoring.
System Compatibility
• Microsoft Excel 2016, 2019, 2021, or Microsoft 365
• Google Sheets / LibreOffice Calc / OnlyOffice
• File Format: .xlsx
Workbook Structure
The workbook contains three dedicated worksheets:
1. Dashboard: Summarizes total income, total expenses, monthly balance, budget alerts, and spending breakdown 
charts.
2. Transactions: Main logging sheet for entering daily income and expense transactions.
3. Categories: Configuration sheet for setting monthly category budget caps.
Quick-Start Guide
1. Open SmartBudget_Manager.xlsx in Microsoft Excel.
2. Navigate to the Categories worksheet and review or adjust monthly budget caps.
3. Open the Transactions worksheet to enter your income and expense transactions.
4. Review the Dashboard worksheet to monitor your net balance, overspending warnings, and category charts.
Critical Data-Entry Rules
• Do not overwrite the Month column in the Transactions sheet; it is calculated automatically via dynamic formulas.
• Use the provided drop-down lists in the Type and Category columns for accurate data entry.
